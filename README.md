# Project Canvas

I want an advanced app that allows me to plan a project.



It should have a sleek, modern appearance, much like an iOS/MAC/Windows 11 aesthetic, with glass morphism effects.



It should allow me to also reference certain words throughout a note to another note or folder.



Add support for sub folders.



Folders and subfolders should have their own overview page, listing all notes and subfolders within that folder, with an optional banner image, unique profile image, description, and a customisable topic tag.



Add a tag list that can be customised with custom tags to explain the topic of that tag.



Add anything groundbreaking when it comes to note taking and project planning, to make this a great notes app for project planning.



Must have support for custom gradient accent colors, and dark and light app theme
